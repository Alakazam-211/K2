# Code lines that still type the command's name (k2, k5), per file and kind:
# `<lines> <kind> <path> <reason>`. Checked by scripts/garden/brand-gate.py
# (scripts/brand-gate.sh runs it). A file may not go over its row, and a
# file with no row for a kind may have none. Never raise a row by hand: use
# CLI_NAME or cli_name!() from k2_core::brand (crates/k2-client/src/brand.rs),
# or CLI_NAME from @/lib/brand (src/renderer/lib/brand.ts). Lower the rows
# with --tighten; the steps that rewrite the text do that in every commit.
#
# Kinds: cli (the command name typed out: a verb, a flag or a placeholder
# after it), value (a string that is exactly "k2" or "k5": a Rust literal,
# or '...', "..." or `...` on a renderer code line; in the bash CLI's parts,
# cli/src and cli/text, also the name as a word in shell code, as
# scripts/garden/cli-name-flip.py finds them), glued (a brand name built
# into a token: a header, a key, a path, a prefix).
# Reasons: `keeper:` stays on purpose (who reads it); `debt:` should move to
# the brand module. A glued row is always `keeper:`.
# A value row says the class of its lines:
#   keeper: <class>[+<class>]; <who reads it>
#   debt: command (<n> lines); <step>[; keeps: <class>; <who reads it>]
# Kept in every brand: stored (on this machine's disk or database, read back
# by our own code), wire (another program of ours reads it: another server,
# the app, an App, the CLI's JSON), outside (a program that is not ours
# holds it), inert (no reader cares). command: the command a person or agent
# types, or its file's name on disk; the step named moves it to CLI_NAME
# (--list value --debt prints them and their total).
# The rule: a kept value never becomes CLI_NAME; a brand does not rename it.
# These rows are kept apart from scripts/brand-allowlist.txt (the product's
# names) so the commits that lower them stay apart too.
