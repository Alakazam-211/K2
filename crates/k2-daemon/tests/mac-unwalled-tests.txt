# k2-daemon tests that start a login shell (a PTY through /usr/bin/login).
# A K2 Compute job on a Mac runs inside a sandbox that refuses that
# program ("Failed to spawn command '/usr/bin/login': Operation not
# permitted"), so there these tests can only fail.
#
# They run on the Mac node that has no job wall; every other k2-daemon
# test runs on the walled Mac nodes. scripts/ci/k2-daemon-mac-tests.sh
# turns this list into the two nextest filters and checks it against the
# test sources. Nothing is skipped inside a test.
#
# One test per line: the test binary (`lib` for the crate's own tests),
# the test's full name as nextest prints it, then why it is here.
