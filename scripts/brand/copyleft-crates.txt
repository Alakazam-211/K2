# Crates a private white-label build can't ship, and bundled C we accept.
# scripts/brand/licence-gate.sh reads it. It refuses a partner brand's
# build (any brand id but k2 and k5) when the tag's Cargo.lock holds a
# refused crate. K5's own builds only get a report.
#
# A refused crate, three fields split by " | ":
#   crate | why partner builds can't ship it | what lifts it
# An allowed crate (never refused; the gate names it in its report):
#   allowed crate | its licence | the rule
# The refusal reads "<brand>: can't build from <tag>: it includes <crate>
# <version>, which partner builds can't ship. This lifts <what lifts it>.",
# then the reason on a line of its own. Take a refused row out only when
# what lifts it has landed and the crate is gone from Cargo.lock.
libgit2-sys | allowed in K2's own builds only; refused for partner builds until gitoxide replaces it | in the first release where gitoxide has replaced libgit2
allowed pg_query | PostgreSQL License | accepted in every build
allowed libsqlite3-sys | SQLite is public domain | accepted in every build
