# Evidence notes

Each note here cites the run record behind every figure it gives, as `[run JOB/RUN:field]`. `tools/evidence/check.py` checks those citations against the records.

The run records themselves (`docs/evidence/runs/`, about 16 MB) live only on the kit's main branch. Public cut tags, which hosts vendor, leave them out, so in a vendored copy a `[run …]` citation names a record that isn't present. To check a figure, read the record at the same path on the kit's main branch.
