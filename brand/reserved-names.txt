# Command names a brand may not take, for scripts/brand.sh lint
# (scripts/brand/lint.py). Tab-separated: <name> <hard|soft> <sources>.
#
# hard: always refused. A system command, a shell builtin or keyword
#   (bash, zsh, fish), a PowerShell or cmd.exe name, a Windows device name
#   (a file of that name can't be made), a developer tool or a common shell
#   alias agents type (an agent terminal puts our folder first on PATH, so
#   the brand's command would hide it), or one of ours and its look-alikes
#   (lint.py also refuses any name that starts k2 or k5).
# soft: refused unless K2 and the Kessel Steward both sign off, in the
#   brand's collision-ok.toml (lint.py's header says how): a name known
#   from a package index only, or one whose environment prefix (<NAME>_)
#   other tools read.
#
# The lists are a floor, not a ceiling: `brand.sh lint --live` also asks
# the build host's shells and the package indexes. Sources: the white-label
# CLI name evaluation, section 4.3, and K2's ruling 6 (developer tools and
# shell aliases are hard).
