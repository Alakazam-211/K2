Multiplayer Markdown demo: 3 agents + 1 person on plan.md (host clock starts 2026-01-01 00:00:00 UTC)
Legend: `who $ doc <verb> ...` is one call of the host's doc CLI; `| ` is stdout;
`stderr:` is stderr; `event:` is a host event; agents' edits run under ClaimPolicy::Respect.
