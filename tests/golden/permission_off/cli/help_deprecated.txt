K2 retired verbs → new equivalents

HARD-DEPRECATED (verb removed; commands exit non-zero with pointer)

  state list|get|set              → (removed — Workspace States retired)
  app-update                      → update --app
  status "msg"                    → organization update "<news>"
  checkin                         → organization bulletin|update, thread, tickets, inbox
  checkin --done                  → done [--blocked "reason"]

  # 0.40.31 — legacy per-agent adaptive heartbeat control removed
  # (heartbeat.json; nothing consumed it since 0.39.0d). Named
  # workspace heartbeat schedules are the only heartbeat surface.

  heartbeat set --agent <n> ...   → heartbeat schedule add/edit --name <n> <spec>
  heartbeat get --agent <n>       → heartbeat show <name> [--json]
  heartbeat force --agent <n>     → heartbeat signal fire <name>
  heartbeat noop|action           → (removed — adaptive backoff is gone;
                                       the user owns wake cadence via schedules)

  --agent <name> flag             → --workspace <path>  (everywhere)
                                       Hard-removed; pass workspace explicitly.

RETIRED (the CLI no longer runs these; each answers with its pointer and
exits 1; /cli/agents/work and /cli/work/inbox answer 410 and point here)

  agents create                   → k2 skills create <name> --role "..."
  agents running                  → k2 workspace list --running
  agents list                     → k2 workspace list  (or k2 skills list)
  agents work                     → k2 inbox
  agents status                   → k2 workspace list
  agents delete                   → k2 skills remove <name>
  agents remove                   → k2 skills remove <name>
  agents launch                   → your harness's own session start (K2 no longer launches agents)
  agents generate-md              → k2 skills regenerate [<name>]
  agents profile                  → k2 skills profile <name>
  agents lock                     → (nothing replaces it)
  agents unlock                   → (nothing replaces it)
  agents triage                   → k2 workspace triage
  agents reap                     → (nothing replaces it)
  agent create                    → k2 skills create <name> --role "..."
  agent delete                    → k2 agent retire <name>
  agent remove                    → k2 agent retire <name>
  work create                     → k2 inbox compose --title "..." --body "..."
  work send                       → k2 msg <workspace> --inbox-silent <file>  (or --inbox-wake)
  work move                       → k2 agent complete --agent <name> --file <file>
  work inbox                      → k2 inbox
  work done                       → k2 inbox archive <id>
  delegate                        → your harness's sub-agent feature, with k2 skills profile <agent>
  mode                            → k2 settings --mode custom  (or off|manager|k2)
  who                             → k2 connections list
  roster                          → k2 connections list
  whatsnew                        → k2 whats-new
  commit-merge                    → k2 commit --merge
  feed                            → k2 activity
  signal                          → k2 msg <workspace> --signal <kind> [--payload <json>]
  companion                       → k2 users pair-phone
  agentic                         → (agentic mode is always on)

EXAMPLES OF MIGRATION

  # Sending a message
  Old: k2 msg --agent scout_v3 "hello"
  New: k2 msg scout_v3 "hello"            # workspace-implicit; --agent removed

  # Marking a task done
  Old: k2 checkin --done --blocked "Stripe API access"
  New: k2 done --blocked "Stripe API access"
