# (scripts/brand-gate.sh runs it). A family may not go over its row, and a
# family with no row may have none. Never raise a row by hand: send the text
# as a {cli} template or build it with CLI_NAME. Lower the rows with
# --tighten; the B7 steps that convert a family do that in the same commit.
#
# `skip <path> <reason>`: a file or folder (ending in /) whose text is not
# printed by a CLI for a person, or is not the server's command. Each one
# needs its reason; a skip for a path that is gone is an error. A skipped
# file is still held line by line by the brand gate's cli rows
# (scripts/cli-name-allowlist.txt).
#
# `keep <path> "<text>" <reason>`: the lines of a file that hold the text
# keep a literal k2 on purpose (a value another program reads, a marker
# read back, text sent to another server, a word that is not our command).
# A keep row that holds back no line is an error. Rebrand step B7 step 1
# moved every other line onto the brand's names.
