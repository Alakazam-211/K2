# K2 brand assets

- `k2-icon-1024.png` / `k2_logo_square_rounded.png` — the K2 mark (app icon
  source; squircle, cream plate). Icon contexts use this alone.
- `k2-lockup-dark-text.png` — lockup with dark "by Alakazam Labs" text:
  use on LIGHT backgrounds (light-mode README, k2.dev light header, DMG).
- `k2-lockup-light-text.png` — lockup with light text: use on DARK
  backgrounds (dark-mode README, dark site headers).

Rule of thumb: icon contexts get the mark, page contexts get the lockup.
The Alakazam wordmark colors are part of the house brand — don't recolor.

## The composite rule

The public brand is **"K2 by Alakazam Labs"** (the composite — see
TRADEMARKS.md). Usage:

- **Anchor every first-contact surface with the composite once**: README
  hero, k2.dev header, About window, DMG window, top of release notes,
  listings/ads. After the anchor, plain "K2" is fine in prose.
- **Functional names stay short by design** (not brand surfaces): the
  `k2` CLI, `K2.app`, bundle id `dev.k2.app`, crates, env vars, domains,
  package names, and the app icon (icons never carry attribution text).
- Use ™ (not ®) until registration issues.
